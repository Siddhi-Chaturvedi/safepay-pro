🔥 The Problem

Today's scams don't necessarily look suspicious.

A victim might receive:

📱 WhatsApp message → Fake investment opportunity → Phone call → Fake SEBI/Bank officer → Payment link → ₹50,000 loss

Existing solutions mostly tell people:

❌ “This is a scam.”

By then, the user may already have clicked the link or transferred money.

Your solution:

Detect → Explain → Intervene → Educate → Report
